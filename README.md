# 基于Ollama FastGPT Dify平台的智能体搭建

## 内容包括：
## 1.本地大模型部署
使用OLLAMA搭建本地大模型，实测2070-8G仅能流畅运行deepseek-7B尺寸模型
小尺寸模型在具体实际运用中效果欠佳，经对比使用官方API接口效果较优
## 2.知识库构建
### RAG示意图
使用FastGPT搭建在线知识库
上传文档，使用encoding模型对文本进行分块编码
![RAG示意图](./rag.png)

## 3.提示词设计
建立工作流时提示词应明确、规范，即用最精简的内容描述工作内容


## 4.工作流搭建
对于单一模型而言，实现单一功能是较好的选择
实地工程搭建时应把复杂功能拆分为子功能，交付给多个模型完成
