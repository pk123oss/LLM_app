## 4.工作流搭建
对于单一模型而言，实现单一功能是较好的选择
实地工程搭建时应把复杂功能拆分为子功能，交付给多个模型完成
### 简单问答功能
简单问答功能，用户输入经RAG整合后给到大模型输入，可根据用户选择进行交互式的ifelse操作
![简单问答工作流](./图片1.png)

### 复杂工作流搭建
图中为工业大数据分析高校智能问答助手的工作流模型，由多个子功能组成的模型构建而成
分别承担了（图片处理/RAG/在线搜索/结果检错）等功能
由于单个模型的输出不具备检错功能，因此针对性的设计回顾检错模型，类似于“纪检部门”
对于整体输出质量和可靠性有着较高的提升
